# Activity tab tooltips

Hovering Processes, Services, Usage or Connections gives a short overview of that view. Processes describes resource comparisons and filtering; Services describes status, resource use and available controls; Usage explains cumulative totals and exited apps; Connections explains endpoint ownership and live readings during captures.

Use the existing tooltip style and localized resources, with no changes to tab labels or selection. Feature smoke checks all four bindings and renders `tab-help-*.png` for visual review.

Landed on 2026-11-07 in MainWindow.xaml and all ten string resource files. No departures from the design.
