# WinMon v4.0.1

WinMon 4.0.1 brings app-level network visibility, more flexible charts and better ways to keep important activity in view. These notes cover changes since v3.5.1.

## See which apps are using your network

- New **Connections** tab groups TCP connections and UDP endpoints by app.
- Search by app name, PID or endpoint; inspect connection details in **Properties**, or jump to the app in **Processes**.
- Pin apps, filter to pinned apps and choose how to rank the list.
- Optional **per-process network monitoring** adds download/upload rates, traffic-history graphs and received/sent totals.
- Review recorded connections alongside resource history in Capture mode.

## Set up network monitoring more easily

- A dedicated **Settings → Network** page brings adapter selection and monitoring controls together.
- Signed desktop installers offer an optional network-monitoring setup step.
- Install, repair or remove the monitoring service from Settings.
- Monitoring reconnects automatically after interruptions and marks gaps in traffic coverage.

Endpoint viewing works without administrator rights or the optional service. Traffic monitoring requires the service and is available in signed desktop builds.

## Get more from your charts

- New **Logical processors** view shows CPU history for each logical processor.
- Collapse the chart to give activity tables more room.
- Each chart type remembers its resource selections, time range and control visibility.
- Choose a **1, 2, 5 or 10-minute peak window**. Peak labels show values such as RAM usage or disk throughput, with timestamps in tooltips.
- New installations retain **30 minutes of history** by default; existing retention settings are preserved.

## Keep important activity close

- Pin Services and use **Pinned only** to focus the list.
- Services remembers sorting, status filters and the Workers setting.
- WinMon remembers the selected activity tab.
- Collapse the shared action bar when you need more table space.

## More details and smoother operation

- Export **Services** and **Connections** observations to CSV.
- Explore the redesigned **Info** window with Hardware, Guide and About tabs.
- Open diagnostic logs directly from About.
- Improved layouts, tooltips and chart controls.
- Fixed a process-list focus crash and reduced monitoring overhead.

Connection history stays in memory and is not restored after restarting WinMon. Connections CSV exports contain endpoint observations; traffic counters are excluded.

## Signing and validation status

Official desktop release packaging uses Azure Artifact Signing for the application, monitoring service, setup helper and installer, plus a separately signed update manifest. See the [code signing policy](../CODE_SIGNING.md).

These notes summarize repository changes. Signing of the v4.0.1 release artifacts, release-package installation and live monitoring have not been verified as part of preparing these notes. Native service acceptance checks remain required before publication.
