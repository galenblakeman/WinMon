# WinMon v4.1.0

WinMon 4.1.0 adds a terminal app and makes it easier to investigate recorded activity, export network traffic and follow an app between views. These notes cover changes since v4.0.6.

## Monitor from your terminal

- New **WinMon.Cli** provides interactive **Processes, Services, Connections and Usage** tabs.
- View CPU, memory, disk, network and GPU gauges, with resource histories and layouts that adapt to the terminal size.
- Search, sort, group and pin apps; open row details and pause the displayed observations while monitoring continues.
- Save terminal preferences separately from desktop settings. Command-line options can override them for one launch.
- Use **snapshot** for a one-shot text or JSON report suitable for scripts.
- Use the optional network service for per-process traffic. Signed desktop-channel CLI builds also provide explicit **network install** and **network start** commands; installation requests administrator approval.

## Follow activity across the desktop

- Use **Show in Connections** or **Show in Usage** from a process row or its More menu to find the same app in the destination view, adjusting filters and row limits when needed.
- In Capture mode, **Usage** shows the recorded period ending at the selected capture. Returning to Live restores session totals.
- Capture mode explains how much history each activity view actually retains, including gaps and shorter coverage.
- Automatic network-peak captures include the apps with the highest recorded receive and send rates, with incomplete readings identified.
- Export retained **Process network traffic** to CSV, including raw byte totals, rates and coverage quality. Endpoint exports remain separate so traffic counters are not repeated for every connection.

## Choose your download

- The desktop installer and portable ZIP now include **WinMon.Cli.exe**.
- A separate **WinMon-Cli-4.1.0-win-x64.zip** is available for terminal-only use.
- The installer offers an unchecked option to add **WinMon.Cli** to your user PATH. Open a new terminal afterward to use the command.
- Both apps are self-contained Windows x64 executables; no separate .NET installation is required.
- The Microsoft Store package continues to provide the desktop app only.

## Fixes and maintenance

- Portable desktop updates now replace both executables and restore their previous versions if the updated desktop fails to start. Existing CLI sessions can finish on their loaded version; restart them to use the update.
- CLI settings saves now tolerate brief file locks while preserving the existing settings if saving ultimately fails.
- Cleaned up stale update downloads left by removed portable copies.
- Refreshed the README, screenshot gallery and user guide.

## Upgrading portable copies

Older portable updaters replace only **WinMon.exe** on their first update to this version. Extract the complete new portable ZIP once to obtain the CLI; later automatic updates service both executables. Preserve your existing settings when extracting. Installed copies receive the CLI through Setup.

CLI-only downloads are updated by replacing their executable manually. Per-process traffic still requires the optional monitoring service; ordinary monitoring does not install it automatically.

---

Official desktop packages use timestamped Authenticode signatures from Galen Blakeman and an RSA-signed update manifest. See the [code signing policy](https://github.com/galenblakeman/WinMon/blob/v4.1.0/docs/CODE_SIGNING.md).

Older-Windows, older-to-newer installation and elevated ETW/UAC acceptance were not rerun for this release.
