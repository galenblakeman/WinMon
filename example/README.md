# WinMon screenshot examples

Captured October 20, 2026, using the WinMon 1.0.2 WPF application. These examples use illustrative process identities and measurements so the screenshots are consistent and do not expose a user's running processes. They are UI examples, not performance measurements.

| File | View |
| --- | --- |
| [example_individual.png](example_individual.png) | Dark live dashboard, individual processes, dual disks and centered Live / Snapshot switch. |
| [example_grouped.png](example_grouped.png) | The same recording grouped by executable, with App / Background labels and private-memory totals. |
| [example_snapshot.png](example_snapshot.png) | An earlier spike selected in Snapshot mode while the top readouts remain live. |
| [example_apps_only.png](example_apps_only.png) | Compact 720-DIP layout with a Chrome search and App Only enabled. |
| [example_light.png](example_light.png) | Light appearance with the Classic palette. |
| [example_neon.png](example_neon.png) | Neon palette. |
| [example_arcade.png](example_arcade.png) | Arcade palette. |
| [example_tropical.png](example_tropical.png) | Tropical palette. |
| [example_settings.png](example_settings.png) | Settings with Neon selected, color swatches, keyboard shortcut and dual-disk choices. |

The default and palette dashboard views use the same illustrative recording. The settings screenshot shows the real Settings controls; its disk choices reflect the capture machine. The existing snapshot card, process rows and native window controls are rendered by the app.
